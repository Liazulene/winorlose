# 下一阶段自主决策框架

## 1. 总目标

在不污染 G0 的前提下，解释 pass、komi 和搜索预算分别如何造成当前现象，并据此做出证据化的下一步决策：继续刻画 G0、创建更丰富的 G1+ 环境，还是进入小型 7×7 迁移试验。

默认不是为了“消灭捷径”。规则允许的最简单策略本身就是结果。下一阶段应同时保留两个研究轨道：

- **G0 原生轨道**：问更强规划是否更可靠地发现当前规则的最优或近优策略。
- **G1+ 构造轨道**：问在明确削弱某种廉价终局后，异质目标是否产生更丰富的互动。

两轨的数据、版本和结论必须隔离。

## 2. 首要研究问题

Q1. 搜索预算从 64 提升到 256/1024 后，G0 中解析短路的采用率如何变化？

Q2. mixed−same 的长度差中，有多少来自共同效用结构，有多少来自早期 pass 和正贴目？

Q3. LOSE/LOSE 的强黑方目标优势是否随 komi 改变而单调变化？是否存在一个与 WIN/WIN 平衡点不同的 `K_LL`？

Q4. shallow MCTS 的落子、丢子和拒绝 pass 有多少是有限样本误判，而不是稳定策略？

Q5. 在不依赖 2–3 手终局的条件下，mixed 协调是否仍跨 seed、跨预算存在？

Q6. 只有在上述机制明确后，7×7 是否能检验“状态空间扩展”，而不是重复同一条规则捷径？

## 3. 建议的最小诊断序列

Dot 可以基于审计调整具体实现，但应优先遵循“先便宜、后昂贵；先单因素、后组合”的顺序。

### D0：解析与脚本基线

新增确定性或近确定性 agent，用于建立机制参照，而不是替代 MCTS：

- `AlwaysPass`：每手 pass。
- `OneStoneThenPass`：首个合法落子后始终 pass。
- `GreedyArea`：一手前瞻，选择即时自身面积最有利动作，并定义稳定 tie-break。
- 可选 `AvoidEarlyPass` 或脚本响应者，仅在问题定义清楚时加入。

必须用单元测试证明行为、终局和目标值。优先跑小型全颜色 matchup 表，验证解析推导和实现一致。

### D1：G0 搜索预算扫描

保持 5×5、komi 2.5、规则、身份、rollout 和 agent 集合不变，只改变 simulations：64、256、1024。

建议先每个关键条件 25–50 局、至少 3 个 batch seed；根据预先定义的置信区间或方向一致性决定扩到 100–200。不要一开始复制完整 56 配对大批次；可先使用颜色与身份分层的代表配对，确认机制后再扩全矩阵。

主要终点：

- mixed 双方目标达成率；
- LOSE/LOSE 黑白各自目标率；
- 长度均值、中位数、Q3、≥60 手比例；
- 2 手、3 手、≤8 手终局比例；
- AlwaysPass / OneStoneThenPass 路线的精确或行为等价采用率；
- 第一 pass 的局面价值、第二 pass 接受率；
- 所选动作 Q 与更高预算复估值的一致性。

### D2：规则机制的单因素对照

首选一个小型 2×2 因子设计：

- komi：2.5 vs 0；
- early pass：原规则 vs 前 8 ply 不允许 pass。

搜索预算固定在 256，其他内容固定。2×2 可以检查交互；如果资源有限，先分别做单因素对照，再补组合格。

注意：`komi=0` 可能引入和棋并改变效用分布；这不是“公平真值”，只是机制探针。`前 8 ply 禁 pass` 是新规则，不是 G0 修复。每个条件必须新命名，例如 `G1-k0`、`G1-pass8`、`G1-k0-pass8`。

### D3：局面级反事实

从旧 Batch B 和 D1/D2 中分层抽取代表局面：

- mixed 的首次 pass 前；
- mixed 的可立即共同终局局面；
- LOSE/LOSE 黑方提议 pass、白方拒绝的局面；
- LOSE/LOSE 白方提议且黑方接受的局面；
- 浅搜索选择丢子动作的局面。

对所有合法候选动作使用更高预算、重复独立随机流或小棋盘穷举近似评估，回答“该动作是否真实改善当前行动方目标”，不要仅把原始根 Q 当作校准概率。

### D4：可选的新效用研究

若研究目标明确转为“受控求输”而非“只要输即可”，可设计 `LOSE-NARROW`：先以输赢为主序，输棋时再偏好较小负分差。示意效用可为：

- 自己输：`+1 - ε * normalized_margin`
- 和棋：`0`
- 自己赢：`-1`

但具体形式必须先做排序不被次级项颠覆的证明和测试。这是新游戏，不能把结果解释为原始 LOSE 的自然延伸，也不应在 D0–D3 未完成前成为默认主线。

## 4. 统计和报告要求

每项实验预先写清：

- 主假设与可证伪预测；
- 唯一自变量和固定因素；
- seed、颜色平衡、配对和每格局数；
- 主终点、次终点和扩样规则；
- 置信区间方法与多重比较处理；
- 中断恢复、完整性和 replay 门槛；
- 哪些结果将触发继续、停止或改设计。

至少报告：

- 每个 seed 和 pooled 结果，不只报告合并值；
- 盘面赢家与身份目标分别报告；
- 黑白分层，不用颜色平均掩盖结构；
- 长度完整分布或关键分位数，不只均值；
- 原始精确前缀和 END 补齐短局敏感性；
- 对称归一化前缀作为补充，不能替代原口径；
- 计算成本、失败、中断、move_limit、superko 活动；
- 代表局的选择规则，避免只挑支持故事的案例。

## 5. 7×7 GO/NO-GO 门槛

以下不是机械 p 值清单，而是最低证据要求。进入 7×7 小型 pilot 前，至少应满足：

1. 已用 D0/D1 明确 shallow 搜索与解析短路的关系。
2. 已用至少一个 pass 或 komi 对照量化规则机制贡献。
3. 关键结论至少跨 3 个独立 batch seed 方向一致。
4. 至少在 256 simulations 下复现；如果 64 与 256/1024 结论相反，先解释预算效应。
5. 若目标是研究“非平凡协调”，该信号在排除 2–3 手廉价终局后仍存在，而不是只由颜色/komi 决定。
6. 明确 7×7 要检验的可证伪命题，并重新估算分支因子、预算、100 手上限和运行成本。

满足后只启动小型 7×7 pilot，不直接上长期训练或大规模生态。pilot 应先验证规则、回放、确定性和成本，再扩样。

若不满足，NO-GO 不是失败：Dot 应根据最大信息增益选择下一项 5×5 机制实验。

## 6. 自主权限

Dot 可以自主：

- 阅读和分析现有材料；
- 新增测试、分析脚本、诊断 agent 和新版本实现；
- 运行小到中等规模的 5×5 诊断实验；
- 根据预注册扩样规则扩充关键格；
- 在门槛满足时启动小型 7×7 pilot；
- 选择比本文更高信息增益的等价实验，但需写出理由；
- 更新新的实验日志、报告和决策记录。

Dot 不应自行：

- 改写或删除既有规格、正式输出、锁定报告和验证证据；
- 用 `--overwrite` 指向任何既有正式目录；
- 把 G1+ 数据混入 G0 汇总；
- 未经说明同时改变多个关键因素后归因；
- 把无学习实验描述为学习、传播或演化；
- 在没有新资源评估和清晰假设时启动 9×9、神经网络训练或无限期大批次；
- 为追求“有趣结果”而隐去合法的简单策略。

## 7. 停止或请求用户决策的条件

出现以下情况应暂停扩张并汇报：

- 新发现表明旧正式结论或回放不可靠；
- 必须破坏既有数据或改变原始 G0 定义才能继续；
- 预计单项实验需要显著超过约一夜的本机计算，且没有先导结果支持；
- 候选效用或规则改变了研究问题，但无法明确命名新游戏；
- 7×7 pilot 需要重新设计终局/计分而不只是参数化；
- 多个合理下一步价值接近，但代表不同研究方向，需要用户选择偏好。

## 8. 实验账本

建议新建并持续维护 `reports/experiment_ledger.md`，每个实验一条记录：

- 实验 ID、日期、代码版本、source fingerprint；
- 问题、假设、配置、seed、计划局数；
- 输出目录和状态；
- 测试、完整性、replay；
- 核心结果和置信区间；
- 与预期相符/相反之处；
- 决策、理由和下一步。

任何“自主决定”都应在账本中留下可回溯理由。
