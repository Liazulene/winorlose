# 可直接交给 Codex Dot 的长期 Goal

下面正文可原样作为 Goal。附件至少应包含核心交接包；如可用，再附历史原始数据包。

---

接手并自主推进 WinAI / LoseAI 围棋实验。你的目标不是机械执行某个固定实验清单，而是在保护现有 5×5 正式成果的前提下，完成下一阶段的机制拆解，持续分析结果并作出证据化的下一步决策，最终判断何时具备进入 7×7 小型迁移试验的条件。

首先完整阅读 `handoff/00_START_HERE.md`、`handoff/01_CURRENT_STATE.md`、`handoff/02_NEXT_PHASE_DECISION_FRAMEWORK.md`，再阅读 `5x5_mvp_spec.md`、`winai_loseai_go_experiment_notes_v2.md`、`AMBIGUITIES.md`、`README.md` 与 `reports/5x5_planning_phase_report.md`。把文档中的事实、建议和原始规格区分开，不把交接建议误当作不可修改的实验指令。

在任何代码改动或实验前，先审计附件是否完整，运行全部测试和 `scripts/verify_delivery.py`，确认既有正式数据、原始设计文档、锁定报告和 source fingerprint 未变化。记录审计结果。若附件不含历史逐局数据，可以先做代码与设计工作，但涉及旧数据逐局复核时必须明确指出缺失并请求数据包，不能假装已验证。

把当前 5×5、komi 2.5、允许 pass、简单 WIN/LOSE 终局效用的实验定义为只读基线 G0。不得覆盖 `outputs/batch_A_seed0`、`outputs/batch_B_shallow_seed0`、`outputs/batch_B_shallow_seed1`，不得改写既有最终报告与验证证据。任何规则、效用、搜索或 schema 的语义改变必须使用新版本、新 source lock、新输出目录和新报告，且与 G0 分开分析。

下一阶段优先解释三个因素：pass、komi 和搜索预算。先建立可测试的解析/脚本基线（至少评估 AlwaysPass、OneStoneThenPass 和一个明确定义的局部基线），再用受控实验判断：更高 MCTS 预算是否更稳定地发现 G0 的合法短路；mixed 比 same 更短有多少来自共同目标、有多少来自早期 pass/正贴目；LOSE/LOSE 的强颜色效应如何随贴目变化；浅搜索的落子、丢子与拒绝终局有多少是有限预算噪声。

候选初始路线是：G0 的 64/256/1024 预算扫描；随后在固定 256 simulations 下做 komi 2.5 vs 0、原 pass vs 前 8 ply 禁 pass 的单因素或 2×2 对照；再对关键局面做高预算动作反事实。你可以选择信息增益更高的等价设计，但必须在运行前写清假设、唯一自变量、seed、颜色平衡、样本量、主终点、扩样规则、停止条件和归因边界。先做小型 pilot，验证实现、成本和效应方向，再按预注册规则扩样。关键结论至少需要 3 个独立 batch seed；报告每个 seed 和 pooled 结果。

始终把合法简单策略视为实验结果，而不是需要隐藏的漏洞。G0 用于研究原生规则下策略会如何服务规则；如要抑制两三手廉价终局、修改 pass 或引入类似 LOSE-NARROW 的效用，建立清楚命名的 G1+ 新游戏。不要为了“有趣”而悄悄改变 G0，也不要用 matchup-specific komi 作为主实验默认规则；贴目扫描可以作为独立机制探针，LOSE/LOSE 平衡 benchmark 也必须单列。

每项正式新运行都必须保留确定性、并发一致性、增量落盘、断点续跑、完整性检查、全量 replay 和来源锁。新增语义应有单元测试、属性测试和恢复/溯源测试。Windows 并发使用受保护入口。不要用 `--overwrite` 指向现有正式目录。

分析至少覆盖：盘面赢家与身份目标、黑白分层、mixed/same 及四种身份方向、长度分布和尾部、2/3/≤8 手终局、第一 pass 与第二 pass 接受、脚本短路采用率、丢子与动作反事实、精确前缀、END 补齐前缀、可选的棋盘对称归一化前缀、计算成本、move limit、superko、异常和代表局。原始根 Q 不是校准概率；代表局按预定规则选择，避免故事化挑例。没有跨局学习时，不使用“协议传播、社会形成、文化、演化”等表述。

持续维护新的实验账本，记录每次自主决策的证据和理由。每完成一个阶段都生成可复现的中文报告，包括配置、版本、命令、验证、结果、限制、原始产物路径和下一步判断。

只有在以下条件基本满足时才进入 7×7 小型 pilot：已经量化 pass/komi 与 shallow 搜索的贡献；关键方向跨至少 3 seeds；至少在 256 simulations 下复现；如果研究的是非平凡协调，则排除两三手廉价终局后信号仍存在；已经写出 7×7 的可证伪预测并重新评估预算、终局上限和成本。满足时先做小 pilot 并验证，不直接启动长期训练或大规模 9×9。若不满足，保持 7×7 NO-GO，选择最大信息增益的下一项 5×5 诊断。

你可以自主实施代码、测试、5×5 小到中等实验、预注册扩样以及满足门槛后的 7×7 小型 pilot。若发现旧数据不可靠、需要破坏既有成果、研究问题发生重大改变、单项计算预计显著超过一夜且缺乏先导证据，或多个方向价值相近但代表不同研究偏好，则暂停并向用户提交证据、备选项和推荐，而不是擅自扩大范围。

完成标准：不是“跑完一组预定命令”，而是形成一条可审计的证据链，解释当前 5×5 现象的主要机制，保留 G0 与新环境的边界，完成至少一轮有验证的诊断—分析—决策循环，并给出有数据支持的 7×7 GO/NO-GO 决策；若 GO，则完成一个可回放的小型 7×7 pilot 和后续建议；若 NO-GO，则明确剩余不确定性及下一项最高信息增益实验。
